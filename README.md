# Stuart Street Apps — Website

Marketing website for Stuart Street Apps, featuring our educational iOS app "Learn About Your United States."

## About

This is the landing page for our app that helps users learn all 50 U.S. states through capitals, memorable facts, an interactive U.S. map, size and population details, quizzes, and achievement tracking.

## Setup

This is a static HTML/CSS website. No build process required.

### Local Development

1. Clone the repository
2. Open `index.html` in your browser
3. Or use a local server:
   ```bash
   # Python 3
   python -m http.server 8000
   
   # Node.js
   npx serve
   ```

### Required Assets

The site expects the following images in the `images/` directory:
- `favicon.png` - Site favicon
